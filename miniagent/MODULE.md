# miniagent —— 可运行的最小 Agent 系统

一个能真跑、能测试、能消融的 mini Agent。内置两个可开关的工程改进点：

| 改进点 | 位置 | 解决什么 |
|---|---|---|
| **观测压缩** | 工具返回 → 回填上下文 之间 | 长观测撑爆上下文 |
| **工具幂等** | 工具调用 → 实际执行 之间 | 重试导致重复副作用 |

## 快速开始

```bash
# 1) 离线演示，不花钱、不联网、结果确定
python -m miniagent.cli --demo -v

# 2) 真实模型（读工作区 .env 里的 DASHSCOPE_API_KEY / QWEN_MODEL）
python -m miniagent.cli --task "在本仓库 docs 里查证据压缩的实测节省率，并说明来源" -v

# 3) 两个改进点的消融
python -m miniagent.cli --ablate

# 4) 测试
python -m pytest miniagent/tests -q
```

```
                │  └──────┬───────┘                       │
                │         ▼                               │
                │  ┌──────────────┐   改进点 B            │

```

## 三个关键设计决定

### 1. 模型接口可替换

```python
class ChatModel(Protocol):
    def chat(self, messages, tools) -> Reply: ...
```

`ScriptedLLM` 让 Agent 的控制流变成**确定性的、可断言的**。
否则每次测试都要打 API，既慢又会因模型输出漂移随机失败。

### 2. 幂等标记在工具上，不在调用方

```python
@dataclass
class Tool:
    ...
    is_write: bool = False     # 决定是否走幂等路径
```

如果让调用方判断"这次要不要幂等"，迟早漏。标记跟着工具定义走。

读工具**不缓存**——缓存读会返回过期数据，比重复读更糟。

### 3. 收敛必须靠结构，不能靠提示词

这是实测出来的。第一版只有提示词约束"信息够了就作答"，真实模型的表现是：

```
连续 8~9 轮换关键词检索，把 12 次工具预算全部烧完才被迫收尾
```

三层结构性收敛：

| 机制 | 作用 |
|---|---|
| 重复调用拦截 | 同工具+同参数直接跳过，回填"别再重复" |
| 观测级去重 | 参数不同但**内容相同**也能识别（按观测哈希） |
| 强制作答 | 达到阈值后**不提供工具**，模型只能输出文本 |

第三层最可靠：移除工具描述比任何提示词都硬。

## 实测数据

真实模型（qwen3.8-flash）跑「查证据压缩节省率」：

```
终止原因：forced_answer（5 步收敛，阈值 4）
prompt 7104 tok / completion 606 tok
观测压缩：10,073 → 3,656 字符（节省 63.7%）
答案正确，并给出文档路径与原文引用
```

离线消融（固定控制流，只改开关）：

| 压缩 | 幂等 | 观测字符 | 幂等命中 |
|---|---|---|---|
| ✗ | ✗ | 1,656 | 0 |
| ✓ | ✗ | 1,277 | 0 |
| ✗ | ✓ | 1,678 | 1 |
| ✓ | ✓ | 1,299 | 1 |

## 踩过的坑

| 坑 | 现象 | 修法 |
|---|---|---|
| 多工具观测串位 | 一个回复里两个工具调用时，观测按顺序对应会错位 | 按 `tool_call_id` 关联 |
| 幂等指标混用 | `idempotent_hits` 与 `prevented` 语义不同，测错断言 | 分开统计：前者=缓存命中，后者=避免的重复副作用 |
| 重复调用绕开幂等 | 循环层先拦掉了，执行器根本没执行，`hits` 恒为 0 | 循环层拦截也计入 `prevented` |
| 提示词约束无效 | 模型换关键词继续刷 | 加观测级去重 + 强制作答 |
| 强制作答返回空 | 有 tool 历史时模型偶发空 content | 追加一次纯文本请求，仍空则如实报失败 |
| 测试依赖 tmp_path | 本机受限环境下 pytest 临时目录 PermissionError | 用工作区相对路径，不让测试依赖无关环境能力 |

## 边界与不含什么

**含**：循环控制、工具注册与校验、观测压缩、幂等执行、trace、消融、测试。

**不含**（有意）：
- 多 Agent 协作
- 长期记忆 / 向量库
- 流式输出
- 人工审批流

这个项目的目标是把**一个循环**做扎实并且可测量，不是做平台。
