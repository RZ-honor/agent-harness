# 执行护栏设计笔记

## 三级分权

工具按读、写、危险三级注册。读工具直接放行；写工具必须携带确认标记，否则
执行器拒绝并返回可解释的拒绝原因；危险工具（删除、清库、外发）在策略层
直接拒绝，不进入执行器。权限位是工具元数据的一部分，而不是提示词里的约定——
规则能落代码就落代码。

## 熔断与重试

同一工具连续失败三次即打开熔断，冷却窗口内所有调用快速失败。熔断器解决的
是"模型在坏工具上无限重试烧预算"的失效模式：没有熔断时，一次服务超时会让
策略代理把全部步数预算耗在同一个调用上。

## 压实与去重的耦合

上下文压实之后，重复调用检查必须保留大输出调用的指纹，否则会出现
压实→重取→再压实的死循环。这是从 HolmesGPT 的 RESET_REPEATED_TOOL_CALL_CHECK_AFTER_COMPACTION
开关反推出的教训，本仓库用独立测试固化该耦合。

## 结论门禁

最终结论中的每条引用必须逐字可回溯到观测原文，匹配粒度为整段原文子串，
短于最小长度的引用直接拒绝。真实引用与篡改引用在对照集上的放行/拦截结果
由 metrics 脚本一键复现。
